      FCF-SBC scenarios

      Yield bands: 3%, 4%, 5%, 6%, 8%. Bear is red, Base is white, and Bull is green. The scenario rail shows the implied one-year return and target price.

      PER bands

      Historical price bands use EPS-based percentiles. PER above 100x is excluded; the forward region uses the analyst +1Y EPS/share estimate when available.

      PSR bands

      Historical price bands use revenue/share percentiles. The forward region uses the analyst +1Y revenue/share estimate when available.
